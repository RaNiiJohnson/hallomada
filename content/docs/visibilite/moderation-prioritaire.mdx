## En bref

Dans la file de [Modération](/admin/moderation), les publications des membres Premium portent l'étiquette **⚡ « Prioritaire »** et passent **en tête**.

## Les règles

- Concerne les offres d'emploi, les annonces et les pages prestataires.
- Dans chaque groupe, les plus récentes restent en premier.
- Pendant la période gratuite, **toutes** les publications sont prioritaires : l'ordre ne change pas encore. La différence se verra avec le Premium payant.

## Comment vérifier

Ouvrez [Modération](/admin/moderation) avec une publication en attente : l'étiquette « Prioritaire » est affichée.
